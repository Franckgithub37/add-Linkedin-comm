Clé API Anthropic

Aucune clé enregistrée.

La clé n'est jamais réaffichée après enregistrement. "Tester la clé" utilise la clé saisie dans le champ, sinon la clé enregistrée.

Modèle

Proxy (facultatif)

Si une URL est renseignée, l'extension envoie la requête au proxy au lieu d'appeler l'API Anthropic en direct. La clé API reste alors côté serveur (webhook n8n, ou la fonction /api/proxy du projet Vercel). Laisser vide pour l'appel direct.
