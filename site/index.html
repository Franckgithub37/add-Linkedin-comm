Réponses LinkedIn

Extension Chrome personnelle. Vous sélectionnez un post ou un commentaire, un raccourci clavier le capture, et le panneau latéral propose quatre commentaires courts, à la première personne : deux en mode "réflexion", deux en mode "point non vu", plus une ligne d'humour en option.

Télécharger l'extension (.zip) Code source sur GitHub

Installation (mode développeur)

  1. Téléchargez l'archive ci-dessus et décompressez-la. Vous obtenez un dossier extension-reponses-linkedin.
  2. Dans Chrome, ouvrez chrome://extensions.
  3. Activez le Mode développeur (interrupteur en haut à droite).
  4. Cliquez sur Charger l'extension non empaquetée et choisissez le dossier extension-reponses-linkedin.
  5. Épinglez l'icône de l'extension dans la barre d'outils (pièce de puzzle, puis punaise).
  6. Clic droit sur l'icône, puis Options : collez votre clé API Anthropic, cliquez sur Enregistrer puis Tester la clé.

Chrome 116 ou plus récent. L'extension n'est pas publiée sur le Chrome Web Store : elle reste un outil personnel.

Raccourcis clavier

RaccourciAction
Alt+Shift+1Enregistre la sélection dans « Post » et ouvre le panneau
Alt+Shift+2Enregistre la sélection dans « Commentaire »
Alt+Shift+3Enregistre la sélection dans « Réponse »
Alt+Shift+GLance la génération

Sur Mac, Alt correspond à la touche Option. En cas de conflit, remappez les raccourcis dans chrome://extensions/shortcuts.

Utilisation

  1. Sur LinkedIn, sélectionnez le texte du post, puis Alt+Shift+1. Le badge de l'icône affiche « P ».
  2. Facultatif : sélectionnez un commentaire, puis Alt+Shift+2 (badge « PC »), puis la réponse d'un tiers avec Alt+Shift+3 (badge « PCR »).
  3. Dans le panneau, choisissez le contexte (Elliacare, OCD, IA, Autre), la longueur (Flash : 1 ligne, Court : 2 lignes, Standard : 3 lignes, toujours en phrases courtes), le niveau d'ironie (0, 1 ou 2), et cochez si besoin « Humour », « 3 fautes » ou « Lien Elliacare ».
  4. Cliquez sur Générer (ou Entrée, ou Alt+Shift+G).
  5. Cliquez sur la petite icône de copie à côté du commentaire choisi, collez-le dans LinkedIn et publiez vous-même. Chaque commentaire contient deux fautes volontaires (trois avec l'option), listées dessous et jamais copiées.

L'extension ne lit la page qu'au moment du raccourci (la sélection seulement), n'écrit rien dans LinkedIn, ne clique sur rien et ne publie rien.

Proxy optionnel (clé côté serveur)

Ce site héberge aussi une fonction /api/proxy, inactive par défaut. Pour ne plus stocker la clé API dans le navigateur :

  1. Dans Vercel, projet de ce site, ajoutez les variables d'environnement ANTHROPIC_API_KEY et PROXY_TOKEN (un jeton aléatoire d'au moins 24 caractères), puis redéployez.
  2. Dans les options de l'extension, renseignez l'URL https://<ce-site>/api/proxy et le même jeton, puis Tester le proxy.

Un webhook n8n qui accepte le même format (system, messages, model, max_tokens, jeton en Authorization: Bearer) fonctionne aussi.

Dépannage rapide

  • Rien ne se passe au raccourci : vérifiez dans chrome://extensions/shortcuts que le raccourci est bien défini (un conflit le laisse vide).
  • Badge « ! » : la sélection était vide, ou la page est protégée (pages chrome://, Chrome Web Store). Rien n'a été écrasé.
  • Clé refusée : ressaisissez-la dans les options, puis « Tester la clé ».
  • Copie impossible : le texte est alors sélectionné automatiquement, copiez-le avec Ctrl+C (Cmd+C sur Mac).
